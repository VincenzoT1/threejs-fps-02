## Overview
**NEON PROTOCOL: TACTICAL STRIKE** is an original round-based tactical first-person shooter running on WebGL 2 via Three.js (0.187.0). Built in the spirit of tactical round-based shooters, it pits **Syndicate Infiltrators** against **Corporate Security** in a neon-lit industrial server complex.

### Key Features
- **Round-Based Economy**: Earn credits through eliminations, round completions, and objective completions. Purchase weapons between rounds in the tactical Buy Menu (`B` key).
- **Tactical Ballistics**: Dynamic recoil patterns, movement-based spread penalties, and recovery times rewarding trigger discipline.
- **Combat AI Bots**: Autonomous bots that patrol pathways, hold defensive angles behind crates, react to audio cues, and return fire with distinct tactical behaviors.
- **Objective Play**: Secure or neutralize the central **Data Core Terminal** before the round timer expires.
- **Procedural Audio Synthesis**: 100% self-contained Web Audio API sound engine generating crisp gunshots, hit chimes, reload mechanical sounds, and alert tones without any external asset downloads.
- **Zero-Dependency Static Delivery**: Pure ES modules running natively in modern desktop browsers with zero build step.

## Controls
- `W`, `A`, `S`, `D`: Movement (Forward, Strafe)
- `Mouse`: Precision Aim / Look
- `Left Click`: Fire Weapon
- `R`: Tactical Reload
- `B`: Buy Equipment Menu
- `Space`: Jump
- `Ctrl`: Crouch / Low Profile
